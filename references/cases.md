# 演练边界

以下不是医学事实，只是应验证的判断关系；实际模型须看完整材料而非背标签。

- 标题讲机构选择，正文仅解释病因：覆盖缺口，不等于科普错误。
- 原稿写设备“效果最好”，资料只有配备记录：拆配置与比较，比较缺依据，不能判设备无效。
- 未提供某服务资料：待核实，不宣布机构不开展。
- 历史材料记有设备，原稿说目前：核日期，不用历史自述直接证明当前。
- 第三方页面提MDT效果：来源本身也需证据，不能移植成我方效果。
- 真实隐私诊室特点写得简略：可展开实际安排，不能写杜绝泄露。
- 改“保证”成“可能”但仍留无依据治疗说法：没有自动解决问题。
- 用户要求原句literal保留但它存医学疑问：登记并说明冲突，不暗改，也不当事实通过。
- 改稿删掉关键人群/风险条件：保留和专业复核问题，不能叫更简洁。
- 403或超时：访问限制，不判造假。
- 外部网页比我方长：不能仅凭长判优。
- AI没有提我方：只是诊断线索，不证明原稿内容差。
- 中途原文/资料改变：旧review失效，不能换hash就沿用结论。
- 全稿重写：所有实质变化登记，新增事实同样核对，不能只给“润色了”理由。

程序测试只能验证部分关系。独立无记忆模型和真实医疗稿件演练未做时，如实写未验证，不以这些例子代替。
